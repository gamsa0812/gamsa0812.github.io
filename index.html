PriDAT: Bloom Filter Query Engine

Final-year research project, supervised by Dr. Dinusha Vatsalan and Mr. Sinthujan Ragunathan. I designed and built the engine that runs all membership and similarity queries on encoded data.

  • Six query types: exact and fuzzy membership, fuzzy frequency, Top-K similarity, numerical/date-time range and fuzzy range
  • Type-specific encodings for text, categorical, numerical, date-time and image data, with Dice similarity for typo-tolerant matching
  • Fuzzy range queries using an adaptive counting Cuckoo filter over Bloom filter fingerprints
  • Three privacy modes per query: none, local DP (randomised response) and global DP (Laplace mechanism)
  • Evaluated accuracy, privacy–utility trade-off and speed on real e-commerce, finance and image datasets
